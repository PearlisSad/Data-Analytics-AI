
# Structured
- organised info
- easily searchable
- relational database
e.g: contact list, product inventory list
# Unstructured
- no predefined info
- text-heavy
e.g: emails, social media posts, video, audio

# Semi-Structured
- some organisational properties

# Time-series
- successive points in time
- uniform intervals(often)
e.g. stock market, weather data

# Cross-Sectional
- multiple sources at a single point in time
e.g: demographic data from national census, sales data from different regions

# Big Data
- can be structured or unstructured
- Extremely large
- difficult to process using traditional methods
- Volume, velocity and variety
e.g: social network data, sensor data from IoT Deviced, online transaction records
